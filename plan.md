# Nama Aplikasi
Pengelolaan aplikasi data shift karyawan

# Tech Stack
Backend: python, flask
Frontend: css, javascript, & boostrapt
database: firebase
hosting: vercel

# rules
- pastikan aplikasi dibuat dengan max 50 baris per file
- pastikan nama function sesuai dengan fungsi utamanya
- frontend berstruktur component bersifat reusable
- logic inti dari aplikasi simpan di controller, model database simpan sebagai model sesuai dengan fungsinya & view template menyesuaikan dengan endpoint

# struktur
main.py = entry point
controller = logic apps
templates = tampilan frontend website
models = logic / tipe data database
